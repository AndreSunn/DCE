## Current policy precedence

V21 excludes explicit automated follow-up whispers in either complete approved transcript primitive before cleaning or Q01–Q14 scoring, regardless of source call type. It also excludes actual continuations of the same enquiry after prior meaningful Sales discussion. Only a grounded FIRST_MEANINGFUL_CONTACT decision can proceed through the remaining eligibility gates. Unknown contact stage stays pending. An online lead, unanswered earlier attempt or initial browsing is not by itself a follow-up.

The v21 policy overrides inherited clauses that allowed follow-ups or used source type alone to establish that route. Historical files and unpromoted candidates are for reference, not alternative current policies. The latest human pause takes precedence over all earlier resume wording.
